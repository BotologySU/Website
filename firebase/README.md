# حماية قاعدة البيانات (Firebase) — مجاني

الملف `database.rules.json` بيقفل قاعدة البيانات:

| الحاجة | قبل | بعد |
|---|---|---|
| قايمة كل الطلبة (أسماء وأرقام) | أي حد يقدر يقراها | الأدمن بس |
| البلاغات، الحسابات المشكوك فيها، نشاط الطلبة | أي حد | الأدمن بس |
| رصيد الكريديت | أي حد يقدر يزوّد رصيده | الطالب يقدر يصرف بس، والزيادة من الأدمن بس |
| الإيقاف ورسايل الأدمن | أي حد يقدر يفك إيقافه أو يكتب رسالة | الأدمن بس |
| كلمة سر حساب طالب | أي حد يقدر يغيّرها | بتتعمل مرة واحدة، والأدمن بس اللي يمسحها |
| طلبات الشحن | أي حد يقدر يوافق على طلبه | الطالب يبعت الطلب بس، والموافقة من الأدمن |

صفحة الأدمن (`?reports`) بتدخل بإيميل وكلمة سر من **Firebase Authentication**، وده مجاني على خطة Spark.

## الخطوات (بالترتيب ده)

1. **فعّل الدخول بالإيميل:** من [Firebase Console](https://console.firebase.google.com) افتح المشروع `botology-su`، وبعدين **Build → Authentication → Get started → Sign-in method → Email/Password → Enable → Save**.
2. **اعمل حساب الأدمن:** في نفس الصفحة، تبويب **Users → Add user**، واكتب إيميلك وكلمة سر قوية. بعد ما يتعمل انسخ الـ **User UID**.
3. **هات الـ Web API Key:** من الترس ⚙️ **Project settings → General → Web API Key**.
4. **ابعت الاتنين** (الـ UID والـ API Key) لـ Claude. الاتنين مش سريين، عادي يتحطوا في الكود. هيحطهم في الموقع وفي ملف الـ Rules ويعمل PR.
5. **بعد ما الـ PR ده يتعمله Merge ويعدّي 10 دقايق:** افتح `?reports` واتأكد إنك بتدخل بالإيميل وكلمة السر.
6. **آخر خطوة:** **Realtime Database → Rules**، امسح اللي موجود، والصق محتوى `database.rules.json` (هيبقى فيه الـ UID بتاعك)، ودوس **Publish**.

> ⚠️ متعملش Publish للـ Rules قبل خطوة 5. لو اتعملت قبلها، صفحة الأدمن مش هتقدر تقرا البيانات لحد ما الكود الجديد يوصل.

## لو حصلت مشكلة

- **عايز ترجع زي الأول بسرعة:** في **Realtime Database → Rules** حط `{"rules":{".read":true,".write":true}}` ودوس Publish.
- **نسيت كلمة سر الأدمن:** من **Authentication → Users** دوس على النقط التلاتة جنب حسابك، واختار **Reset password**.
- **التقرير اليومي على تليجرام:** بقى بيتبعت لما صفحة الأدمن تتفتح، لأنه محتاج يقرا نشاط كل الطلبة، ودي حاجة الأدمن بس يقدر يعملها.
